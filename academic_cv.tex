\section*{Research Interests}
My research operates at the confluence of \textbf{Real-Time Interactive AI Systems}, \textbf{Virtual Worlds \& Serious Games}, and \textbf{Voice-Enabled Multimodal Agent Architectures}. Grounded in mathematical foundations of Signal Processing and Machine Learning, my investigations prioritize:
\begin{itemize}
    \item \textbf{Real-Time Interactive AI \& Serious Games:} Building intelligent agent architectures and dynamic behavioral scaffolding inside 3D virtual environments (Unity) via event-driven WebSockets, replacing static scripted game trees with adaptive agency.
    \item \textbf{Voice-Enabled Multimodal Agent Architectures:} Sub-second streaming conversational loops (\texttt{ASR $\rightarrow$ LLM $\rightarrow$ TTS}), conversational turn-taking dynamics, dynamic persona modulation, and cognitive scaffolding for clinical assistive interventions (Autism Spectrum Disorder / ASD).
    \item \textbf{Signal Processing \& Applied Machine Learning Foundations:} Rigorous grounding in stochastic processes, statistical signal estimation, temporal state sequences, edge computer vision, and systematic evaluation of multimodal foundation models (Vision-Language Models).
\end{itemize}
